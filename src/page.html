I got the Glove80 and couldn't find a good trainer that helped me find the right keys. I built this to help me — maybe it is useful for somebody else too.

Your stats, keymaps and reading list stay in this browser's local storage — not cookies, never sent anywhere. The whole trainer is one HTML file: grab it from GitHub and run it locally if you'd rather not load it from the web at all.
